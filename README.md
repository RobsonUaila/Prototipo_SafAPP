# Prototipo_SafAPP

# Sistema de Aluguer de Filmes

Este é um sistema de locação de filmes desenvolvido com **Node.js** no backend, permitindo que os usuários aluguem, devolvam e gerenciem suas locações de forma fácil e eficiente.

## Funcionalidades

- Cadastro de usuários e filmes
- Pesquisa de filmes disponíveis
- Locações e devoluções de filmes
- Histórico de locação do usuário
- Notificações sobre devoluções pendentes

## Stack Tecnológico

- **Backend:** Node.js
- **Banco de Dados:** MySQL
- **Framework:** Express
- **Autenticação:** JWT (JSON Web Tokens)
- **Gerenciamento de Pacotes:** npm
